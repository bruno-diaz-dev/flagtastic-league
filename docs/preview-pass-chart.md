# Preview pass chart

This branch is intentionally not merged into main. Apply e6a0b2548c17 only to the preview database. Production continues using the prior deployment and schema.

The public chart uses only confirmed, nonvoid sporting captures. Passing summaries count completed passes, attempts and passing touchdowns; a defensive interception is not attributed to a quarterback. Yardage, expected completion probability, GPS tracking and line of scrimmage are unavailable and are not inferred.

Optional location capture uses normalized integer coordinates from 0 to 100; attack always points toward the top, regardless of actual field direction. Open the placement disclosure before selecting a receiver to suppress one-tap submission, mark departure and arrival, and press Register. Keyboard users can enter the four numeric coordinates. Closing the disclosure submits without location. Geometry travels with the existing durable idempotent outbox payload. Reusing a UUID with different geometry is rejected.

Replay follows recorded endpoints when available; unlocated captures remain explicitly illustrative. Curves depict flight stylistically rather than measured ball paths. Void corrections remove both the statistical contribution and public map marker while preserving internal audit history.
